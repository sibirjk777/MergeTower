# THE LAST THRESHOLD — Slice 01

## Цель
Первый полноценный игровой фрагмент для PC и смартфона.

## Flow
Врата Храма → Площадь Статуй → Каэль → Центральная статуя → Хранитель → Механизм Памяти → мини-игра колец → Глаз Памяти → видение Ирис → тайный проход → катакомбы.

## UX
Один источник GameState. Единый InputMapper: move / look / interact / attack / jump / inventory. Touch-слой отображается только в exploration.

## Ассеты
Порядок производства: окружение → Каэль → Хранитель → статуя → механизм → Глаз Памяти → memory vision → катакомбы.

## Acceptance
Игрок должен пройти Slice 01 без перезагрузки страницы, получить артефакт и открыть путь вниз. Управление должно работать с клавиатурой и touch.
