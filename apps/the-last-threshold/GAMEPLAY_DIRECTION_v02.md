# КНИГА ПОРОГА — GAMEPLAY DIRECTION v02

## Основная игра

Основа игры — полноценная 2D/2.5D adventure-platformer.

Игрок большую часть времени:
- бегает;
- прыгает;
- делает двойные прыжки после получения способности;
- карабкается по вертикальным маршрутам;
- избегает ловушек;
- исследует секреты;
- встречает существ;
- возвращается в ранее открытые зоны.

Мини-игры НЕ должны заменять бродилку. Они возникают только из взаимодействий с важными объектами, персонажами и механизмами.

## Цель темпа

Ориентир прохождения:
примерно 75–85% времени — исследование и платформинг;
примерно 15–25% — интерактивы, головоломки, мини-квесты и мини-игры.

Мини-игра должна либо:
1. давать артефакт;
2. открывать новый маршрут;
3. раскрывать часть истории;
4. менять состояние мира;
5. давать ресурс или способность.

Никогда не вставляем мини-игру только ради разнообразия.

## Книга Порога

Книга является мета-механикой поверх платформера.

Игрок может открыть книгу в любой подходящий момент.

Книга показывает:
- карту;
- воспоминания;
- реликвии;
- сведения о существах;
- найденные символы;
- активные загадки.

Книга не превращает игру в квестовый интерфейс. Основное управление всегда возвращается к бегу и прыжкам.

## Типы интерактивов

### Каменная печать

Рен касается печати.

Запускается короткая логическая мини-игра с символами.

Награда: путь открывается.

### Алтарь

Запускается ритуальная последовательность.

Нужно повторить комбинацию, увиденную ранее в книге.

Награда: контрольная точка и изменение мира.

### Существо

Некоторых существ можно победить обычным боем.

Других нужно изучить через Книгу.

После наблюдения открывается слабое место.

### NPC

Диалог короткий.

После разговора может появиться мини-квест:
- принести предмет;
- найти потерянную вещь;
- провести NPC через участок;
- решить загадку;
- выбрать один из двух способов помочь.

### Особые объекты

Сундук, механизм, дверь, статуя, фрагмент стены, древний прибор могут запускать:
- три в ряд;
- последовательность символов;
- поиск предметов;
- вращение колец;
- мини-лабиринт;
- короткую реакционную игру;
- небольшой merge-механизм.

## Merge Tower внутри Книги Порога

Идея из Merge Tower не переносится как отдельная основная игра.

Она переосмысливается как мини-игра **«Слияние Печатей»**.

Когда Рен находит древний механизм, появляется небольшое поле 4x4.

Игрок объединяет одинаковые рунические фрагменты.

Например:

Осколок I + Осколок I = Печать II

Печать II + Печать II = Печать III

Печать III открывает механизм.

Это позволяет сохранить идею merge из предыдущего проекта, но полностью подчинить её миру «Книги Порога».

## Примеры

### Древний подъёмник

Рен прыжками добирается до механизма.

Взаимодействие → «Слияние Печатей».

После победы подъёмник включается.

Игрок снова возвращается к платформингу.

### Сломанная статуя

Взаимодействие → мини-игра вращения фрагментов.

После сборки статуи появляется короткое воспоминание Миры.

### Запертая камера

Взаимодействие → три в ряд.

При победе выпадает ключевой ресурс.

### Старик-хранитель

Диалог → мини-квест.

Игрок исследует комнату, находит предмет и возвращается.

### Существо-хранитель

Первое столкновение — обычный платформинг и бой.

После изучения существа через книгу становится доступна более эффективная атака.

## Главное правило дизайна

Игрок должен хотеть открыть следующий проход прежде всего ради вопроса:

**«Что находится дальше?»**

Мини-игра — инструмент для усиления этого любопытства.

Не превращать каждый объект в отдельное меню.

## Новая последовательность игры

Платформинг
→ исследование
→ заметный объект
→ взаимодействие
→ короткая мини-игра или квест
→ награда
→ изменение мира
→ новый маршрут
→ снова платформинг.

Именно этот цикл становится основой всей игры.
