# ASSET + LORE PIPELINE

Все новые элементы проекта создаются по назначению и сразу раскладываются по структуре.

## ART

characters/ — Рен, Мира, NPC.
creatures/ — враги, мини-боссы, боссы.
environments/ — крупные фоновые элементы зон.
props/ — интерактивные предметы.
items/ — обычные предметы.
artifacts/ — реликвии.
ui/ — элементы интерфейса.
vfx/ — визуальные эффекты.
tilesets/ — наборы платформ и окружения.

## DATA

story/ — сюжетные флаги и последовательности.
characters/ — параметры персонажей.
creatures/ — игровые параметры врагов.
items/ — предметы и награды.
levels/ — данные уровней.
puzzles/ — конфигурации головоломок.
minigames/ — параметры мини-игр.
lore/ — история мира.

## QUALITY GATE

Перед добавлением ассета проверяется:
- нужен ли он реальному gameplay;
- используется ли он в конкретной сцене;
- читается ли его назначение;
- подходит ли стиль проекта;
- не дублирует ли существующий ресурс.

Каждый значимый персонаж, враг или интерактивный объект получает связанный art + data комплект.

## ИМЕНА

Формат:
TYPE_NAME_VARIANT_vNN

Примеры:
REN_IDLE_v01.svg
MIRA_MEMORY_v01.svg
GUARDIAN_ATTACK_v01.svg
ALTAR_MEMORY_v01.svg

## ЛОР

Лор хранится отдельно от кода.

Сюжетная информация не должна быть единственным образом зашита в UI или canvas-рендер.

Каждая важная сюжетная сущность должна иметь источник данных.

## ПРОЦЕДУРНЫЕ АССЕТЫ

SVG и процедурная графика допустимы на этапе прототипа и для части финального стилизованного набора.

Для showcase-версии постепенно заменять временные элементы на полноценные production assets.

Нельзя выдавать процедурный placeholder за финальный иллюстративный ассет.
