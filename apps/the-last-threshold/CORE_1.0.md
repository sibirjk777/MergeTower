# THE LAST THRESHOLD — CORE 1.0

## Назначение

Единый слой для контекстных действий, интеракций, состояния мира, артефактов и мини-игр. Он специально изолирован от текущего single-file vertical slice.

## Компоненты

- EventBus — события без жёсткой связи между системами.
- WorldState — единое состояние мира.
- InteractionTarget — стандартизированный интерактивный объект.
- InteractionSystem — выбор лучшей интеракции в зоне игрока.
- ContextActionSystem — выбор активной кнопки.
- ArtifactSystem — постоянные артефакты и эффекты.
- MiniGameRegistry — единая регистрация мини-игр.

## Приоритет контекста

1. Бой, если враг находится в боевой зоне.
2. Критическая интеракция.
3. Обычная интеракция.
4. NONE.

Ветка main не затрагивается. Рабочая ветка — Monty.


## Интеграция Slice 07

В test/index.html Core 1.0 теперь используется не только для выбора кнопки, но и для фактического выполнения интеракций через ThresholdCoreAPI.executeInteraction().

Зарегистрированные игровые цели: bag, mechanism, mira, sign:*, secret, totem, cache, altar, gate.

Legacy-логика сохранена только как исполняемые действия конкретных целей; монолитная проверка всех объектов внутри interact() удалена. Это позволяет добавлять новые интерактивы без разрастания центрального обработчика.

Следующая архитектурная веха: связать ArtifactSystem и MiniGameRegistry с реальными наградами и интерактивными сценами, затем вынести Slice 07 из single-file в модульные gameplay-системы.
